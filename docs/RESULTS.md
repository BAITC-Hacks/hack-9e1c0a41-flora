## Метод (для README и питча)
- **Оптимальное обучение** (Warren Powell, Peter Frazier): выбор каждого пилота по Knowledge Gradient —
  ожидаемому приросту ценности итогового плана.
- **Коррелированные убеждения**: `θ = β0 + β1·m0 + u`, калибровка истории учится по всем пилотам сразу.
- **Эмпирический Байес** (Bradley Efron): разброс «история → аудитория» (постоянная часть и часть,
  пропорциональная конверсии) оценивается по правдоподобию пилотов; если история не предсказывает пилоты,
  агент перестаёт ей доверять.
- **Отбор по нижней границе** (z = 0.5 для проверенных пилотом, 1.0 — только по калибровке), каналы
  push / sms / digital_ads под ценность абонента, остаток контактов — в бесплатный push.
- Детерминирован: `submission.csv` воспроизводится байт в байт.
