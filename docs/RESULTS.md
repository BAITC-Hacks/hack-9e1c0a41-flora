## v5: правило риска по состоянию модели (решение 15:10)
Проблема (найдена независимым ревьюером): в «трудных» мирах калибровка по пилотам завышает оценки непроверенных
ячеек (пилоты ставятся на самые перспективные связки — «проклятие победителя»), и бесплатный push по ним
уходит в минус. Правило: если эмпирический Байес выбрал разброс «история → аудитория» ≥ 1,5 априорного,
push по непроверенным ячейкам не делается, а порог для них — z = 1,5 вместо 1,0.

Проверка: два параллельных прогона (агенты-исполнители), сетка из 5 настроек, одинаковые seed.
Размер выборки небольшой (27 прогонов на набор): улучшение худшего случая держится на одном мире набора 300.

| Стенд | v4: среднее / худший | **v5: среднее / худший** |
|---|---|---|
| Реалистичный (`tools/realistic_bench.py`), набор реализаций 300: 9 миров × 3 seed = 27 прогонов | 11,98 млн / −2,24 млн | **12,24 млн / −0,22 млн** |
| Реалистичный, набор реализаций 100: 9 миров × 3 seed = 27 прогонов | 15,90 млн / +3,57 млн | **16,06 млн / +3,57 млн** |
| Стресс-стенд, 15 сценариев × 3 seed (0–2) = 45 прогонов | 9,11 млн / +1,85 млн | 9,11 млн / +1,85 млн |

Отвергнуто: порог 3,0 (не отличается от v4 в трудных мирах), z = 2,0 (хуже худший случай на стресс-стенде).

## Метод (для README и питча)
- **Оптимальное обучение** (Warren Powell, Peter Frazier): выбор каждого пилота по Knowledge Gradient —
  ожидаемому приросту ценности итогового плана.
- **Коррелированные убеждения**: `θ = β0 + β1·m0 + u`, калибровка истории учится по всем пилотам сразу.
- **Эмпирический Байес** (Bradley Efron): разброс «история → аудитория» (постоянная часть и часть,
  пропорциональная конверсии) оценивается по правдоподобию пилотов; если история не предсказывает пилоты,
  агент перестаёт ей доверять.
- **Отбор по нижней границе** (z = 0.5 для проверенных пилотом, 1.0 — только по калибровке), каналы
  push / sms / digital_ads под ценность абонента, остаток контактов — в бесплатный push.
- **MILP-планировщик** (scipy/HiGHS): целые ячейки, точный учёт контактов, бюджета, лимита 10 кампаний
  и 5 000 абонентов; при ошибке солвера — запасной жадный отбор.
- **Правило риска по состоянию модели**: если пилоты показали, что история ненадёжна, агент не делает
  push по непроверенным ячейкам и повышает для них порог (защита от «проклятия победителя».)
- Детерминирован: `submission.csv` воспроизводится байт в байт.
