# Flora — агент тарифных маркетинговых кампаний (Beeline, HackAlem AI)

> Статус: **в разработке** (HackAlem AI, 23.09.2026). README обновляется по ходу работы.

## Кратко
Кейс 04 «Beeline Tariff Marketing Campaigns». Агент на синтетической базе из 23 441 абонента
сам проверяет гипотезы пилотными кампаниями и возвращает план не более чем из 10 кампаний
(сегмент → целевой тариф → канал) в рамках бюджета 100 000 у.е. и 15 000 контактов.

## Быстрый старт
```bash
pip install -r requirements.txt
python local_eval.py              # один прогон на мок-среде
python local_eval.py --runs 10    # устойчивость по 10 seed
python make_submission.py         # формирует submission.csv
```
На Windows для корректной кириллицы в консоли: `set PYTHONIOENCODING=utf-8`.

## Журнал результатов (мок-среда, seed 42)
| Версия | Чистый результат | Комментарий |
|---|---:|---|
| шаблон организаторов | −1 035 279 | шумные пилоты → убыточная кампания на 2 950 абонентов |
| v1: априорная оценка по истории + пилоты + нижняя граница | +1 849 433 | 10/10 seed в плюсе, медиана +2,30 млн; 16 из 20 пилотов ушли на одну бесполезную связку |
| v2: Knowledge Gradient + калибровка истории по пилотам + эмпирический Байес + выбор канала | +5 739 498 | 10/10 seed в плюсе, медиана +5,68 млн, минимум +4,97 млн |

Мок-среда построена из той же истории, что и априорная оценка агента, поэтому её числа завышены.
Честная проверка — `python stress_eval.py`: 9 сценариев, где эффекты расходятся с историей
(сдвиг, шум, смена знака, перемешивание, отсутствие связи с историей и др.).
v2: все 45 прогонов в плюсе, медиана +5,77 млн, худший +1,66 млн; шаблон уходит в минус в большинстве сценариев.
