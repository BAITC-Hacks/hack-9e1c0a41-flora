# Flora — агент тарифных маркетинговых кампаний (Beeline, HackAlem AI)

> Статус: **в разработке** (HackAlem AI, 23.09.2026). README обновляется по ходу работы.

## Кратко
Кейс 04 «Beeline Tariff Marketing Campaigns». Агент на синтетической базе из 23 441 абонента
сам проверяет гипотезы пилотными кампаниями и возвращает план не более чем из 10 кампаний
(сегмент → целевой тариф → канал) в рамках бюджета 100 000 у.е. и 15 000 контактов.

## Быстрый старт
```bash
pip install -r requirements.txt
python local_eval.py              # один прогон на мок-среде
python local_eval.py --runs 10    # устойчивость по 10 seed
python make_submission.py         # формирует submission.csv
```
На Windows для корректной кириллицы в консоли: `set PYTHONIOENCODING=utf-8`.
